# Wildberries — Google Sheets (Apps Script)

Набор скриптов для **Google Таблиц**: выгрузки и отчёты по API Wildberries, меню в таблице, опционально уведомления в Telegram.

Токены **не хранятся в коде** — вводятся через меню (`PropertiesService`).

## Файлы (порядок в проекте Apps Script)

| Файл в репозитории | Назначение |
|--------------------|------------|
| `00_headers_ru_*.txt` | Русские заголовки колонок WB |
| `01_downloads_*.txt` | Главное меню, токен API, основные загрузки |
| `02_reports_*.txt` | Отчёты |
| `03_postavka*.txt` | Поставки FBW |
| `04_print*.txt` | Печать / этикетки |
| `05_seller_stocks_*.txt` | Остатки |
| `06_fbs_orders_*.txt` | Заказы FBS |
| `07_fbs_supplies_*.txt` | Поставки FBS |
| `08_fbs_compose_*.txt` | Сборка FBS |

> В Google Apps Script создайте файлы `.gs` и вставьте содержимое из соответствующих `.txt`. Файл `00_headers` должен загружаться первым (как в комментариях в `01_downloads`).

## Установка

1. Google Таблица → **Расширения** → **Apps Script**.
2. Создайте файлы по таблице выше, вставьте код из `.txt`.
3. Сохраните проект, обновите таблицу — появится меню **WB Аналитика**.
4. **Ввести API токен** — токен из личного кабинета WB (категории по подсказке в диалоге).
